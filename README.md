# Contrato Perú Fibra

Generador de speech y contrato para ventas de Perú Fibra (clon adaptado de contrato-win-02-25).

## Uso
1. Elige tipo de cliente (DNI/CE/RUC 10 o RUC 20).
2. Llena velocidad y mínimo (primeros 6 meses y posterior), precio mensual e instalación.
3. Opcional: "Guardar como plan" para reutilizarlo con un clic (se guarda en el navegador).

## Publicar en GitHub Pages
1. Crea un repo nuevo (ej. `contrato-peru-fibra`) y sube estos archivos.
2. Settings > Pages > Deploy from a branch > `main` / root.
3. Quedará en `https://TU-USUARIO.github.io/contrato-peru-fibra/`
